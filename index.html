1

Prepare your poster

Use a one-slide PowerPoint poster. Download the APHA PowerPoint template below. Its poster size is 36 inches wide × 21 inches high (landscape). You can also use an existing poster with the same proportions.

↓ Download APHA PowerPoint template (36 × 21 inches)
Export the poster as PNG
In PowerPoint for Windows: select File → Export → Change File Type → PNG Portable Network Graphics Format → Save As. When prompted, select Just This One or Current Slide Only. Keep both the .pptx and the PNG.

Your files are processed in this browser. Review all extracted text, charts, and sections before sharing the finished poster.

Select your files

Choose the PowerPoint and the PNG exported from that same slide.

3

Select and review sections

On the poster, drag a rectangle around each section. Include the section heading, text and any charts you want visitors to see. Then select each numbered area to review its text.

Tip: For a wide results area, create one selection for the full area or make smaller sections for individual charts. Text inside images or grouped objects may need to be typed or pasted into the editor.

Editing section

Charts remain visible in the selected poster image. Enter chart descriptions or values in the text above so they can be read aloud.

Add presenters

Add presenters in the order you want them to appear. Photos and email addresses are optional.
